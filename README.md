# Price Optimization Analysis

## Description
This project uses regression analysis to estimate price elasticity and identify optimal pricing points that maximize revenue.

## Tools Used
- Python
- Pandas
- Statsmodels
- Matplotlib
- Excel (Data preparation)

## Key Steps
- Loaded historical pricing and sales data
- Cleaned and validated the dataset
- Built a regression model to estimate demand-price relationship
- Identified revenue-maximizing price point
- Provided business pricing recommendation

## Files
- price_optimization.ipynb : Jupyter notebook with full analysis
- sales_pricing_data.csv : Dataset
- screenshots/ : Output screenshots
